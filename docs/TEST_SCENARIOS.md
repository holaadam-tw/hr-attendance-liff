### E. 失敗判定

出現任一項即視為跨公司隔離失敗：

- 本米 admin 看到大正員工姓名
- 大正 admin 看到本米請假或薪資
- 切公司後仍殘留上一家資料
- 公告 / 設定 / 地點改動影響另一家公司
- 匯出報表混入另一家公司資料
